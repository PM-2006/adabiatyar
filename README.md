# ادبیات‌یار — MVP v0.5

ساختار جدید هر درس:

- A) حفظیات
  - مقدمه
  - واژه‌نامه: درسنامه + جعبه لایتنر
  - املا
- B) معنی و مفهوم: درسنامه + سؤال
- C) آرایه: درسنامه + تمرین تشخیص آرایه + سؤال
- D) دستور زبان: درسنامه + سؤال
- E) قلمرو: فکری / ادبی / زبانی، هرکدام عادی و پیشرفته
- F) روان‌خوانی / حکایت / شعرخوانی
- G) سؤالات امتحان نهایی
- H) جمع‌بندی

## تگ سؤال‌ها

هر سؤال فقط یک بار در JSON ذخیره می‌شود و با `tags` در چند بخش قابل نمایش است. مثال:

```json
{
  "tags": ["آرایه", "امتحان نهایی", "خرداد ۱۴۰۴"]
}
```

این سؤال هم در بخش آرایه و هم در امتحان نهایی دیده می‌شود.

## پنل ادمین

`/admin`

تب‌های پنل با ساختار جدید درس یکسان هستند. Import فایل JSON قدیمی نیز پشتیبانی می‌شود و داده قدیمی به ساختار جدید مهاجرت می‌کند.
